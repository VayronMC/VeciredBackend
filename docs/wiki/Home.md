# VeciRed — Wiki del Backend

Bienvenido a la documentación extendida del backend de **VeciRed**.

## ¿Qué es VeciRed?

Plataforma web comunitaria que conecta vecinos para ofrecer y solicitar ayuda en categorías como servicios, favores y préstamos.

## Repositorios del proyecto
