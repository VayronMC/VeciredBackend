# Wiki VeciRed Backend

Contenido para la Wiki de GitHub del repositorio **VeciredBackend**.

## Cómo activar la Wiki

1. Ve a **GitHub → VeciredBackend → Settings → Features**
2. Activa **Wikis**
3. Abre la pestaña **Wiki → Create the first page**
4. Copia el contenido de cada archivo de esta carpeta como página nueva
